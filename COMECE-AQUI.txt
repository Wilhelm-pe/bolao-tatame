BOLÃO DO TATAME — COMO COLOCAR NO AR (±12 min, tudo grátis)
===========================================================

Site de um arquivo (index.html) + Firebase grátis como banco em tempo
real. Cada amigo aposta do próprio celular; VOCÊ (organizador) entra
com e-mail e senha para conferir os Pix e aprovar os pagamentos.


PASSO 1 — CRIAR O FIREBASE (grátis, sem cartão)
-----------------------------------------------
1. https://console.firebase.google.com  (login Google) → "Adicionar
   projeto" → nome (ex.: bolao-tatame) → pode pular Analytics → Criar.

2. Menu "Criação" (Build):

   a) FIRESTORE DATABASE → "Criar banco de dados"
      - Pode começar em "modo de teste" (troque pelas REGRAS do passo 3).
      - Local: southamerica-east1 (São Paulo).

   b) AUTHENTICATION → "Vamos começar" → aba "Sign-in method", habilite
      DOIS métodos:
        • "Anônimo" (Anonymous)  → deixa a galera apostar sem conta.
        • "E-mail/senha" (Email/Password) → é o SEU login de organizador.

3. CONFIG do site: engrenagem → "Configurações do projeto" → "Seus apps"
   → ícone WEB </> → registrar → copie o conteúdo de { ... } do bloco
   "const firebaseConfig".


PASSO 2 — COLAR A CONFIG NO SITE
--------------------------------
Abra index.html, lá no começo do <script type="module"> tem:
   const firebaseConfig = { apiKey:"", authDomain:"", projectId:"", ... };
Substitua pelos valores copiados. Salve.
(Essas chaves podem ser públicas; quem protege são as REGRAS do passo 3.)


PASSO 3 — REGRAS DO FIRESTORE (a blindagem!)
--------------------------------------------
Firestore Database → aba "Regras" → apague tudo, cole isto, Publicar:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /salas/{sala} {
      function salaCfg() {
        return get(/databases/$(database)/documents/salas/$(sala)).data;
      }
      function ownerOf() { return salaCfg().ownerUid; }
      // Janela de horário: só deixa apostar se status=aberto E dentro do intervalo.
      function janelaAberta() {
        let c = salaCfg();
        return c.status == 'aberto'
          && (!('abreTs' in c) || c.abreTs == null || request.time.toMillis() >= c.abreTs)
          && (!('fechaTs' in c) || c.fechaTs == null || request.time.toMillis() <= c.fechaTs);
      }
      // Qualquer um LÊ a luta (nomes curtos, cotação). Só o DONO escreve.
      allow read: if true;
      allow create: if request.auth != null
                    && request.resource.data.ownerUid == request.auth.uid;
      allow update: if request.auth != null
                    && resource.data.ownerUid == request.auth.uid
                    && request.resource.data.ownerUid == resource.data.ownerUid;
      allow delete: if false;

      // Aposta pública (nome curto, lado, valor): cada um cria a SUA,
      // e SÓ dentro da janela de horário (o servidor recusa fora dela).
      match /apostas/{uid} {
        allow read: if true;
        allow create, update: if request.auth != null && request.auth.uid == uid
                              && janelaAberta();
        allow delete: if request.auth != null
                      && (request.auth.uid == uid || request.auth.uid == ownerOf());
      }
      // Confirmação de pagamento: SÓ o organizador escreve.
      match /pagos/{uid} {
        allow read: if true;
        allow write: if request.auth != null && request.auth.uid == ownerOf();
      }
      // Dados privados (NOME COMPLETO, CPF, Pix): o próprio e o organizador LEEM.
      match /privado/{uid} {
        allow read: if request.auth != null
                    && (request.auth.uid == uid || request.auth.uid == ownerOf());
        allow create, update: if request.auth != null && request.auth.uid == uid;
        allow delete: if request.auth != null
                      && (request.auth.uid == uid || request.auth.uid == ownerOf());
      }
    }
  }
}

O que isso garante (de verdade, no servidor do Google):
  • Ninguém troca a sua chave Pix — só o DONO escreve a configuração.
  • Ninguém se marca como "pago" — só o DONO confirma pagamento.
  • NOME COMPLETO e CPF ficam escondidos de todos, menos do organizador
    (e do próprio dono do dado). Nem pelo console dá pra ler.
  • Cada pessoa só mexe na própria aposta.
  • FORA do horário (antes de abrir ou depois de fechar) o servidor RECUSA
    a aposta — nem pelo console dá pra forçar.


PASSO 4 — SUBIR NA VERCEL
-------------------------
- vercel.com → Add New → Project → Import do seu repositório do GitHub
  (bolao-tatame) → Deploy. Sai a URL do site.
- Ou arraste a pasta (sem GitHub).


PASSO 5 — VIRAR ORGANIZADOR E CONFERIR PAGAMENTOS  ← SUA DÚVIDA
--------------------------------------------------------------
1. Abra o site → role até "Painel do organizador".
2. Na PRIMEIRA vez: digite seu e-mail + senha (mín. 6) e toque em
   "Criar conta". Pronto — essa conta vira a DONA da sala.
   (Nas próximas vezes é só "Entrar", de qualquer celular/PC seu.)
3. Preencha a luta, SUA CHAVE PIX e a % da bolsa. Se quiser, defina
   "Abre em" e "Fecha em" (a janela de apostas) → "Salvar luta".
   Fora desse horário o site fecha sozinho e ninguém consegue apostar.
   Deixando em branco, você abre/fecha na mão nos botões.
4. Mande o link pra galera. Cada um se cadastra (nome completo + CPF),
   vê o Pix na tela e paga. A aposta entra como "pendente".

COMO VOCÊ CONFERE E APROVA:
  • Abra o app do SEU BANCO e veja o Pix caindo (nome/valor).
  • No site (logado como organizador) você vê, em cada aposta, o
    NOME COMPLETO e o CPF — confira com o que caiu no banco.
  • Bateu? Toque em "✓ pago". A aposta vira verde e entra no bolo.
  • Errou? O "↺" desfaz. O "✕" remove a aposta.
  • Só apostas PAGAS contam no bolo e na cotação.
  • No fim: "Venceu Azul/Vermelho" → sai o rateio com nome e Pix de
    cada acertador pra você pagar.

IMPORTANTE: o login de organizador funciona em qualquer aparelho seu —
é só entrar com o mesmo e-mail e senha. Os apostadores NUNCA precisam
de conta.


VÁRIAS LUTAS (mesmo site, não precisa de outro repositório)
-----------------------------------------------------------
NÃO precisa criar outro diretório nem subir outro site. O MESMO link,
com um #nome no final, já vira uma sala nova e separada:
   .../            -> sala "principal"
   .../#esposte2   -> outra luta, outro pool, outro resultado
   .../#card-03    -> mais uma
Cada #nome tem o próprio organizador (quem salvar a luta primeiro),
a própria chave Pix, a própria janela de horário e o próprio rateio.
Dá pra ter várias lutas rolando ao mesmo tempo, cada uma no seu link.
